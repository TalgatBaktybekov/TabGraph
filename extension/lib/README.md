# Vendored libraries

- `Readability.js` — Mozilla Readability v0.5.0, unmodified, from
  https://unpkg.com/@mozilla/readability@0.5.0/Readability.js
  (source: https://github.com/mozilla/readability). Loaded as a classic
  script via `chrome.scripting.executeScript`, which defines the global
  `Readability` constructor used by `content.js`.
